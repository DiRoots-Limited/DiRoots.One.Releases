DiRootsOne은 BIM 전문가가 더 빠르게 작업하고 반복 작업을 줄이며 모델 및 문서화 워크플로를 개선할 수 있도록 설계된 13개의 Autodesk Revit 애드인을 하나로 묶은 통합 애플리케이션 패키지입니다.

DiRoots 도구 간의 원활한 상호 운용성을 통해 DiRootsOne은 모델 데이터 관리, 요소 필터링 및 검사, 도면 제작 자동화, 포인트 클라우드 작업, 일상적인 Revit 작업 간소화를 지원합니다.

### DiRootsOne 패키지에 포함된 기능
- SheetLink
Revit 모델 데이터(카테고리, 요소, 일람표별)를 Excel 및 Google 스프레드시트로 내보냅니다. 데이터를 편집한 후 다시 가져와 모델을 업데이트할 수 있습니다.

- FamilyReviser
Revit 패밀리(이름 변경, 접두사와 접미사 추가, 체계적인 저장)와 작업 세트(카테고리별 수정 또는 사용자 규칙 생성)를 관리합니다.

- OneFilter
Revit 모델에서 패밀리를 빠르게 찾아 색상으로 표시합니다. 카테고리, 매개변수 이름 및 값으로 검색하고 면적, 매스, 룸, 공간 및 구역 내 요소를 찾을 수 있습니다.

- TableGen
스프레드시트를 범례 뷰, 일람표 뷰 및 드래프팅 뷰로 Revit에 가져옵니다. Revit을 사용하지 않는 사용자와 협업하고 Excel 표를 Revit으로 가져올 수 있습니다.

- SheetGen
여러 도면 시트를 만들고 사전 정의된 템플릿에 따라 뷰를 배치하며 시트 리비전을 손쉽게 관리합니다. 시트/뷰 목록을 Excel로 내보내거나 Excel에서 가져올 수 있습니다.

- ReOrdering
접두사, 접미사 및 승수를 사용하여 Revit 인스턴스 매개변수의 번호를 쉽게 다시 지정합니다(수동 또는 경로/상세 선을 따라 실행).

- ParaManager
프로젝트 및 패밀리 환경에서 Revit 매개변수를 관리합니다. 새 매개변수를 만들거나 기존 매개변수를 수정하고, Excel 및 공유 매개변수 파일로 내보내거나 가져옵니다. 공유 매개변수를 사용자 친화적인 방식으로 편집할 수 있습니다(메모장 불필요).

- PointKit
포인트 클라우드 작업 시 생산성을 높여 주는 Autodesk Revit 애드인입니다.

- QuickViews
룸이나 공간에서 내부 입면도, 단면도 및 콜아웃을 손쉽게 생성하는 Autodesk Revit 애드인입니다.

- OneParameter
Revit 모델의 인스턴스/유형 매개변수 값을 한 번의 클릭으로 일괄 편집하는 Autodesk Revit 플러그인입니다.

- SectionBoxer
선택한 요소에서 여유 공간이 포함된 단면 상자를 빠르게 만들고, 필요한 경우 새 뷰에 생성하여 해당 요소를 분리된 상태로 더 쉽게 검사하거나 조작할 수 있습니다.

- Hide in Views
여러 Revit 뷰에서 선택한 요소와 카테고리를 빠르게 숨기거나 표시하여 가시성을 표준화하고 문서를 더 효율적으로 준비할 수 있습니다.

- ViewAligner
ViewAligner는 참조 뷰를 템플릿으로 사용하여 Revit 시트에서 뷰를 배치하는 과정을 간소화합니다.
