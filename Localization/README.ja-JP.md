DiRootsOne は、BIM プロフェッショナルの作業効率向上、反復作業の削減、モデルおよびドキュメントのワークフロー改善を目的として設計された、13 種類の Autodesk Revit アドインをまとめた統合アプリケーションパッケージです。

DiRoots ツール間のシームレスな連携により、DiRootsOne はモデルデータの管理、要素のフィルタリングと検査、図面作成の自動化、点群の操作、日常的な Revit 作業の効率化を支援します。

### DiRootsOne パッケージに含まれる機能
- SheetLink
Revit モデルのデータ（カテゴリ、要素、集計表別）を Excel および Google スプレッドシートにエクスポートします。データを編集して再インポートすることで、モデルを更新できます。

- FamilyReviser
Revit ファミリ（名前変更、接頭辞と接尾辞の追加、整理された形式での保存）およびワークセット（カテゴリ別の変更や独自ルールの作成）を管理します。

- OneFilter
Revit モデル内のファミリをすばやく検索して色分けします。カテゴリ、パラメータ名、値で検索でき、エリア、マス、部屋、スペース、ゾーン内の要素も検索できます。

- TableGen
スプレッドシートを凡例ビュー、集計表ビュー、製図ビューとして Revit にインポートします。Revit を使用しないユーザーと共同作業し、Excel の表を Revit に取り込めます。

- SheetGen
複数の図面シートを作成し、定義済みテンプレートに基づいてビューを配置して、シートの改訂を簡単に管理します。シートとビューの一覧を Excel へエクスポート、または Excel からインポートできます。

- ReOrdering
接頭辞、接尾辞、乗数を使用して、Revit のインスタンスパラメータを簡単に振り直します（手動、またはパス／詳細線に沿って実行）。

- ParaManager
プロジェクト環境とファミリ環境の Revit パラメータを管理します。パラメータの新規作成と変更、Excel や共有パラメータファイルとの間のエクスポート／インポートが可能です。共有パラメータを使いやすい画面で編集できます（メモ帳は不要です）。

- PointKit
点群を扱う際の生産性を高める Autodesk Revit アドインです。

- QuickViews
部屋やスペースから内部立面図、断面図、吹き出しを簡単に作成できる Autodesk Revit アドインです。

- OneParameter
Revit モデル内のインスタンス／タイプパラメータの値を、ワンクリックで一括編集できる Autodesk Revit プラグインです。

- SectionBoxer
選択した要素から、余白付きの断面ボックスをすばやく作成します。必要に応じて新しいビューに作成し、要素を分離した状態でより詳しく検査または操作できます。

- Hide in Views
複数の Revit ビューで選択した要素やカテゴリをすばやく非表示／再表示し、表示設定の標準化とドキュメント作成の効率化を支援します。

- ViewAligner
ViewAligner は、参照ビューをテンプレートとして使用し、Revit シート上でのビュー配置を効率化します。
