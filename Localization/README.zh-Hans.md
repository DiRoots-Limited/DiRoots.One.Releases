DiRootsOne 是一个集成应用程序包，汇集了 13 个 Autodesk Revit 加载项，旨在帮助 BIM 专业人员提高工作效率、减少重复性任务，并改进模型和文档工作流程。

凭借 DiRoots 工具之间的无缝互操作性，DiRootsOne 可帮助您管理模型数据、筛选和检查图元、自动生成图纸、处理点云，并简化日常 Revit 工作。

### DiRootsOne 程序包包含
- SheetLink
将 Revit 模型数据（按类别、图元和明细表）导出到 Excel 和 Google 表格。编辑数据后将其重新导入以更新模型。

- FamilyReviser
管理 Revit 族（重命名、添加前缀和后缀并有序保存）和工作集（按类别修改工作集或创建自定义规则）。

- OneFilter
在 Revit 模型中快速查找族并为其着色。可按类别、参数名称和值进行搜索，还可查找面积、体量、房间、空间和区域内的图元。

- TableGen
将电子表格作为图例视图、明细表视图和绘图视图导入 Revit。与不使用 Revit 的人员协作，并将 Excel 表格引入 Revit。

- SheetGen
创建多个图纸，根据预定义模板放置视图，并轻松管理图纸修订。将图纸/视图列表导出到 Excel 或从 Excel 导入。

- ReOrdering
使用前缀、后缀和乘数轻松为 Revit 实例参数重新编号（手动操作或沿路径/详图线操作）。

- ParaManager
管理项目和族环境中的 Revit 参数。创建新参数、修改现有参数，并与 Excel 和共享参数文件互相导入/导出参数。通过友好的界面编辑共享参数（无需使用记事本）。

- PointKit
用于提高点云工作效率的 Autodesk Revit 加载项。

- QuickViews
用于从房间/空间轻松创建室内立面图、剖面图和详图索引的 Autodesk Revit 加载项。

- OneParameter
只需单击一次，即可批量编辑 Revit 模型中实例/类型参数值的 Autodesk Revit 插件。

- SectionBoxer
根据所选图元快速创建带有缓冲区的剖面框，还可选择在新视图中创建，以便更好地单独检查或操作这些图元。

- Hide in Views
在多个 Revit 视图中快速隐藏或取消隐藏所选图元和类别，帮助统一可见性并更高效地准备文档。

- ViewAligner
ViewAligner 使用参照视图作为模板，简化在 Revit 图纸中定位视图的过程。

### 支持的 Revit 版本
2018、2019、2020、2021、2022、2023、2024、2025、2026 和 2027。
