DiRootsOne 是一套整合式應用程式套件，集合了 13 個 Autodesk Revit 附加元件，旨在協助 BIM 專業人員提升工作效率、減少重複性工作，並改善模型與文件工作流程。

透過 DiRoots 工具之間的無縫互通，DiRootsOne 可協助您管理模型資料、篩選與檢查圖元、自動產生圖面、處理點雲，以及簡化日常 Revit 工作。

### DiRootsOne 套件包含
- SheetLink
將 Revit 模型資料（依類別、圖元和明細表）匯出至 Excel 和 Google 試算表。編輯資料後再匯入，以更新模型。

- FamilyReviser
管理 Revit 族群（重新命名、新增前綴與後綴，並以有條理的方式儲存）和工作集（依類別修改工作集或建立自訂規則）。

- OneFilter
在 Revit 模型中快速尋找族群並加上色彩。可依類別、參數名稱和值進行搜尋，也可尋找面積、量體、房間、空間和區域內的圖元。

- TableGen
將試算表以圖例視圖、明細表視圖和製圖視圖的形式匯入 Revit。與未使用 Revit 的人員協作，並將 Excel 表格帶入 Revit。

- SheetGen
建立多張圖紙，依預先定義的範本放置視圖，並輕鬆管理圖紙修訂。將圖紙/視圖清單匯出至 Excel 或從 Excel 匯入。

- ReOrdering
使用前綴、後綴和乘數，輕鬆為 Revit 實體參數重新編號（手動操作或沿著路徑/詳圖線操作）。

- ParaManager
管理專案與族群環境中的 Revit 參數。建立新參數、修改現有參數，並與 Excel 和共用參數檔案互相匯入/匯出參數。透過友善的介面編輯共用參數（不再需要記事本）。

- PointKit
用於提升點雲工作效率的 Autodesk Revit 附加元件。

- QuickViews
可從房間/空間輕鬆建立室內立面圖、剖面圖和詳圖索引的 Autodesk Revit 附加元件。

- OneParameter
只需按一下，即可批次編輯 Revit 模型中實體/類型參數值的 Autodesk Revit 外掛程式。

- SectionBoxer
根據所選圖元快速建立具有緩衝區的剖面框，並可選擇在新視圖中建立，以便更妥善地單獨檢查或操作這些圖元。

- Hide in Views
在多個 Revit 視圖中快速隱藏或取消隱藏所選圖元和類別，協助統一可見性並更有效率地準備文件。

- ViewAligner
ViewAligner 使用參照視圖作為範本，簡化在 Revit 圖紙中定位視圖的流程。

### 支援的 Revit 版本
2018、2019、2020、2021、2022、2023、2024、2025、2026 和 2027。
